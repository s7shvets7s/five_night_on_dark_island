# Island Night Watch — 5 ночей на загадочном острове
[](image/mainmenu.png)
FNAF-like survival horror для Yandex Games, не прошла модерацию по некоторым причинам которые связаны с тематикой игры.Для создания использовались бесплатные ии инструменты аналогично моей [первой игрe] (https://github.com/s7shvets7s/slavic-dungeon).Репозиторй содержит по сути готовую игру, с некоторыми оговорками.

Переживи 7 ночей на заброшенном острове. Следи за камерами, управляй дверями и маскировкой, чини генератор — и не дай им!!! добраться до тебя.

## Стек

- HTML5 / CSS3 / Vanilla JS (ES Modules)
- Canvas 2D API — рендеринг
- Web Audio API — звук
- Yandex Games SDK v2 — платформа
- Никаких фреймворков, сборщиков и TypeScript

## Запуск

```bash
npx serve .
# или
python -m http.server 8000
```

Открой `http://localhost:3000` (или :8000) в браузере.

## Дисклеймер

Автор категорически осуждает любые формы насилия в реальной жизни. Персонажи игры имеют реальные прототипы — фигурантов дела Джеффри Эпштейна, чьи преступления долгие годы оставались безнаказанными. Данная игра является художественным произведением в жанре survival horror и служит лишь способом привлечь внимание к проблеме, а не прославить или романтизировать насилие. События и обстоятельства, показанные в игре, вымышлены.
